# NEOP Web Console

基于《产品开发设计手册_NEOP.md》实现的 Vue 3 前端管理控制台原型，覆盖国家级登记运营、外勤管理、设备生命周期、离线同步、财务审批支付、反欺诈、安全审计等核心页面。

## 技术栈

- Vue 3
- Vue Router
- Vite
- lucide-vue-next
- 原生 CSS 设计系统

## 运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 页面模块

- 全国运营总览
- 外勤操作员管理
- 生物识别设备管理
- 离线同步监控
- 登记质量与异常
- 薪酬审批工作台
- 支付对账中心
- 安全审计中心
- 系统架构视图
